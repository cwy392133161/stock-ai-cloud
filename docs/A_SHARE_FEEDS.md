# A 股行情可用性与故障保护

日常收盘采集先尝试东方财富，再由独立腾讯源核验整份行情。

- A 股优先使用 AKShare 的新连接 HTTP 传输，直接保留东财原始 f 字段；不使用 AKShare 的列投影。
- 东财 A 股最多 5 分钟、200 次请求及 4 次普通 HTTP/连接失败。每个 HTTP 请求只尝试一次。
- HTTP 401/403/429、502/503/504、AKShare Push2RateLimitError 或 push2 RemoteDisconnected 会结束本轮东财采集，并转到已有腾讯备用源。以 503 为例，从四台同源服务器降至一次请求，省去最多 30 秒固定等待。
- 其他错误或字段质量失败仍可尝试下一台东财服务器，前提是请求和时间预算均未耗尽。
- 腾讯按原有分页、分批和间隔采集，10 分钟期限在发起请求和等待重试前检查。当过时的有成交报价已超过全市场总数的 5%，即使剩余全为新鲜报价也无法通过 95% 门槛，提前结束采集。
- Daily 对全市场选股、趋势复核、历史更新分别设 16、12、5 分钟进程上限，最多再给 10 秒清理。任一失败均保留既有榜单，通过原状态流程记录失败。运行跨午夜或报价日期与运行日期不一致时拒绝写入快照。
- 预算只在本次进程有效，不是跨工作流的持久冷却。请勿连续手动触发排障。
- 评分公式、字段覆盖率及股票筛选门槛不变；失败继续保留旧快照。

## 字段与候选源

AKShare 1.20.34 的 interfaces.json 记录：东财 f6/f21 成交额/流通市值为元，涨幅及换手为百分数，成交量为手。f9 是动态 PE，不能用 f115 或其他源的 TTM PE 替代。

2026-11-10 只读核查：
- 新浪现有接口缺 7 个必要评分字段。即便保留原始 per/pb/nmc/turnoverratio，仍缺 60 日、YTD、量比，per 也未验证等价动态 PE。
- 腾讯 stock_zh_a_spot_tx 实测 HTTP 200、5580 只；存在 ltsz/zdf_d60/zdf_y/hsl/lb/pn/turnover，但只有 pe_ttm，没有动态 PE。本版接口未提供单位元数据，无报价时间戳。不可直接接入现有评分。
- 雪球是逐股接口，可能需要 token，公开输出不含 60 日及量比，不是现成全市场备用源。
- 东财 AKShare 全市场/沪深京拆分只是同源接口，不算独立备用。

## 无 AI 验证

`python market_probe.py --market A` 或在 Read-only market data probe 手动选择 A。默认 A，港股可显式选择 HK。探针只读取行情并打印质量结果。

探针记录采集时间，另外逐只检查东财的 `f124` 或腾讯的报价时间。两源都要求至少 95% 的有成交证券满足当日时效条件。盘中允许最多 10 分钟延迟，午休接受 11:28 或之后的报价，收盘后要求达到北京时间 15:00。报价超前检查时间超过 60 秒或未通过时效检查的证券不能入榜。行情还须通过原有的市场完整性和字段覆盖率检查。数据源是否恢复，以盘后实际采集结果为准。
