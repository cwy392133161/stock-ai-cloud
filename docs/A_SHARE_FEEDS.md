# A 股行情可用性与故障保护

本次仅修复同源重试放大和诊断能力，不声称恢复行情源。

- A 股优先使用 AKShare 的新连接 HTTP 传输，直接保留东财原始 f 字段；不使用 AKShare 的列投影。
- 每个 HTTP 请求只有一次尝试；整个 A 股快照最多 200 次请求、最多 4 次 HTTP/连接失败。
- HTTP 429、AKShare Push2RateLimitError、push2 RemoteDisconnected 立即停止整个本轮 A 股采集。不会再调用同源全市场或沪深京拆分接口。
- 普通服务器错误可以换服务器；质量不合格的数据仍可尝试下一服务器，但始终受请求预算限制。
- 预算只在本次进程有效，不是跨工作流的持久冷却。请勿连续手动触发排障。
- 评分公式、字段覆盖率及股票筛选门槛不变；失败继续保留旧快照。

## 无 AI 验证

`python market_probe.py --market A` 或在 Read-only market data probe 手动选择 A。默认 HK 保持兼容。只读取行情并打印质量结果，不写 docs，不请求 AI，不发布网站。

探针时间是采集时间，不是交易所报价时间。当前质量门槛检验完整性，不足以证明交易日/报价新鲜度；源恢复仍需要盘后真实全市场验证。不能把盘前零成交或旧缓存当作当日收盘数据。
